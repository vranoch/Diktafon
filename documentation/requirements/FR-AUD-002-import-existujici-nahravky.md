**Priorita:** MUST / MVP

## Popis

[POTVRZENO] Uživatel může importovat existující nahrávku z úložiště nebo externího diktafonu prostřednictvím systémového výběru souboru (Storage Access Framework).

## Akceptační kritéria

- [ ] Import přes systémový file picker je dostupný z hlavní obrazovky (AT-002).
- [ ] Po odebrání externího média (USB/karta, ze které byl soubor importován) lze import stále zpracovat.
