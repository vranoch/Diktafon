# _workspace/

Dočasný scratch prostor — negitovaný (viz `.gitignore`), kromě tohoto README. Slouží pro:

1. **Staging vstupů** — surový materiál (poznámky, exporty, přepisy diskuzí), který se má
   přetavit do trvalého dokumentu v `documentation/`; po zpracování se zdrojový soubor smaže.
2. **Ad-hoc ladění/analýzu** — dočasné výstupy bez potřeby je verzovat.
3. **Referenční data pro generování** — podklady pro jednorázovou úlohu, jejíž výstup skončí
   v kódu/dokumentaci, zdroj se po dokončení smaže.

Nic z obsahu této složky (kromě tohoto README) by nemělo být trvalou součástí repozitáře —
pokud ano, patří to přesunout jinam.
